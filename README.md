Лабораторная работа №6 по фреймворку Flutter. Приложение отображает случайную мотивирующую цитату и соответствующее ей изображение из встроенного списка при нажатии на кнопку.

## Структурная схема проекта
В соответствии с техническими требованиями, код распределен по трем отдельным файлам в папке lib/:
lib/main.dart - точка входа в программу. Инициализирует запуск приложения и отключает отладочный баннер DEBUG.
lib/quote_screen.dart - экран со состоянием (StatefulWidget). Хранит массив данных, отображает градиентный фон и управляет логикой случайного переключения цитат.
lib/quote_card.dart - компонент карточки (StatelessWidget). Принимает текстовые данные, картинку и колбэк кнопки через параметры конструктора для отрисовки интерфейса.

## Ответы на вопросы

**1. В чем разница между StatelessWidget и StatefulWidget во Flutter?**
StatelessWidget представляет собой неизменяемый виджет. Его свойства инициализируются один раз при создании и не могут динамически меняться во время жизненного цикла экрана. Он используется для статического контента. StatefulWidget обладает изменяемым состоянием (State). Он способен динамически перерисовывать интерфейс при изменении внутренних данных или действий пользователя.

**2. Для чего используется метод setState() и что он делает?**
Метод setState() используется для уведомления фреймворка Flutter о том, что внутренние данные виджета изменились. Он сигнализирует системе о необходимости повторного вызова метода build(), что приводит к мгновенному обновлению элементов интерфейса на экране устройства (в нашем случае — к выводу новой цитаты и картинки).

**3. Как правильно подключить папку с картинками в файле pubspec.yaml?**
Папка регистрируется в секции flutter: под ключом assets:. Путь указывается с новой строки, начинается с дефиса и обязательно должен заканчиваться косой чертой (/), чтобы фреймворк автоматически импортировал все файлы из этой директории:
yaml
flutter:
  assets:
    - assets/images/

В файле pubspec.yaml строго критично соблюдать отступы пробелами и избегать использования символов табуляции.
